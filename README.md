# EQUAR

Reproductor de música para Android: catálogo enorme, ecualizador de 8 bandas, letras, descargas y una interfaz cuidada. Sin anuncios.

## Descargar

Entra en **[Releases](https://github.com/vareoz/equar-app/releases/latest)** y baja el APK:

- **Equar-celular.apk** — teléfonos y tablets.
- **Equar-tv.apk** — Android TV.

Para instalar un APK, tu teléfono te pedirá permitir «instalar apps de orígenes desconocidos».
